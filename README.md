# HealthMate

HealthMate is a personal health and wellness tracker for Android. It lets a user record their daily steps, calories burned and water intake, and review their history.

> Status: in development (Kingston University top-up, Mobile Application Development coursework)

## Features
- Add daily health records (steps, calories burned, water intake)
- View a list of past records with dates
- Update and delete existing records
- Search and filter records by date
- Dashboard summary of today's activity

## Tech Stack
- Android Studio
- Java
- SQLite (local database)
- MVVM architecture

## Project Structure
The code is organised by feature (dashboard, records, add record) with a separate data layer for the database. This section will be updated as the app is built.

## How to Run
1. Clone this repository
2. Open it in Android Studio and wait for Gradle to sync
3. Run the app on an Android emulator or a physical device
